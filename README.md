# Quote Generator

A small web app that shows a random quote every time you click a button.

## Features

- Shows a random quote each click
- Built with HTML and JavaScript
- Quotes are stored in an array

## How to run it

1. Download or clone this repo
2. Open `index.html` in your browser

## What I learned

- How to pick a random item from an array using `Math.random` and `Math.floor`
- How to change text on a page with `textContent`
